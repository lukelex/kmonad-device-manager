# KeyboarDeer — first branding concept

Proposed name for the KMonad GUI configurator. Suggested subtitle:
**A visual configurator for KMonad.**

## Artwork

- [`logo.svg`](logo.svg): full, transparent deer-at-the-keyboard illustration.
  The deer sits behind the table, looks at the viewer, and rests its front
  hooves on a slightly tilted keyboard. Only the tabletop edge is visible.
- [`icon.svg`](icon.svg): compact app-icon study with a cream background,
  reduced antler detail, and a minimal keyboard.

Both are self-contained SVGs without fonts or external resources. Open them
in a browser or vector editor. These are initial concepts, not final artwork.

## Visual direction

| Color | Hex | Use |
| --- | --- | --- |
| Forest | `#253d35` | Outlines, antlers, hooves |
| Chestnut | `#b77c51` | Deer |
| Cream | `#f6ead5` | Muzzle, keyboard case, icon background |
| Sage | `#d6dccc` | Keyboard keybed |
| Warm tan | `#e6b990` | Inner ears |

Use **KeyboarDeer** as the display spelling to make the pun readable.
Before finalizing, test unprompted pronunciation and spelling with a few
people, check software-name and domain availability, and review the icon at
32, 48, and 128 pixels. A dedicated tiny-size mark and a monochrome version
can follow once the main silhouette is approved. Name availability has not
yet been checked.
