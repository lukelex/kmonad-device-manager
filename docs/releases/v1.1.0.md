# KMonad Device Manager v1.1.0

KMonad Device Manager 1.1.0 is a Linux/Core release that adds manager API
contracts while retaining independent systemd supervision when no API client is
connected.

## Highlights

- **Trustworthy preview attribution:** model validation results identify the
  exact submitted behavior candidate with a SHA-256 digest. Rejected diagnostics
  include a source range only when the manager can prove it belongs to one
  submitted `deflayer` assignment.
- **Durable apply recovery:** managed configuration mutations require an opaque
  idempotency key. Retrying a lost response with the same request returns the
  original operation—even after a manager restart—without running a second
  mutation. Conflicting reuse is rejected.
- **Controlled configuration content:** read external UTF-8 `.kbd` source at
  its current content revision through the same-user API, or export an immutable
  manager-rendered managed artifact with `manager_rendered_kbd`. Neither route
  exposes manager paths or grants the client process control or file-write access.
- **Release safety:** tag releases now run the full container verification,
  coverage threshold, static versioned build, and tag/package/changelog/release
  note consistency checks before publishing artifacts.

## Upgrade notes

- API clients must inspect `manager.get` capabilities at runtime.
- Durable `configuration.apply`, `configuration.create`,
  `configuration.update`, `configuration.set_enabled`,
  `configuration.delete`, and `configuration.adopt` requests require a
  non-empty `idempotency_key` of at most 128 bytes.
- `configuration.content.get` reads external source only; use
  `configuration.export` with `manager_rendered_kbd` for a managed artifact.
  Exported content is device-bound and is not a portable profile.
- The physical two-keyboard Linux/evdev acceptance scenario remains documented
  in `TODO.md`; automated container, socket, restart, and lifecycle coverage
  passed for this release.

## Verification and installation

Linux `amd64` and `arm64` archives include SHA-256 checksums, SPDX SBOMs, and
GitHub build provenance attestations. Verify a download with:

```sh
sha256sum -c SHA256SUMS
gh attestation verify <archive> --owner lukelex
```

Install the extracted archive with its included `install.sh`, or use the Arch
package. See `kmonad-device-manager --help --json` and the Wiki API contract for
complete CLI and same-user API details.
