# KMonad Device Manager v1.0.0

KMonad Device Manager 1.0.0 is the first stable major release of the Linux
systemd manager. It is a Linux-only release: it supervises KMonad mappings
independently of GUI/API clients and does not add macOS or Windows support.

## Highlights

- **Safe per-keyboard supervision:** each configured `.kbd` mapping is
  validated with `kmonad --dry-run` and launched from the exact immutable
  snapshot that passed validation. Invalid updates keep the known-good mapping
  running and report the failure.
- **Managed configuration lifecycle:** create, validate, apply, update,
  enable, disable, delete, and adopt configurations through the CLI or local
  API. Revision checks, activation confirmation, and rollback protect a
  working mapping from a failed replacement.
- **Linux device management:** discover connected keyboards without exposing
  private device paths, retain disconnected records, distinguish manager-owned
  virtual outputs from configurable inputs, and identify a selected keyboard
  with a bounded keypress session.
- **Local automation API:** a same-user Unix-socket JSON Lines API v1 provides
  snapshots, events with replay/resynchronization, managed configuration
  operations, diagnostics, and manager/capability metadata. Every public CLI
  command supports meaningful JSON output.
- **Operational safety:** bounded requests and command queues, per-keyboard
  failure isolation, process identity checks, cgroup cleanup, watchdog-aware
  health, Prometheus metrics, and structured `--doctor --json` diagnostics.

## Upgrade notes

- The supported runtime remains **Linux with a systemd user service** and a
  KMonad configuration using `input (device-file "...")`.
- Use `--status --json`; the former `--status=json` spelling has been removed.
- Managed behavior models must not define `defcfg`, `device-file`, or
  `uinput-sink`. The manager owns Linux input/output rendering and validation.
- Existing external `.kbd` files remain independently supervised. API or GUI
  availability is never required for reconciliation, recovery, or stopping a
  mapping.

## Verification and installation

Release archives are provided for Linux `amd64` and `arm64`, with SHA-256
checksums, SPDX SBOMs, and GitHub build provenance attestations. Verify a
download with:

```sh
sha256sum -c SHA256SUMS
gh attestation verify <archive> --owner lukelex
```

Install the extracted archive with its included `install.sh`, or use the Arch
package. See the README and `kmonad-device-manager --help --json` for complete
Linux installation and command details.
